# ModFactory Fabric Development Client

## Setup

This is the runnable Minecraft 1.21.11 development project used by ModFactory.

From the repository root on macOS:

```bash
./scripts/mac-dev.sh build
./scripts/mac-dev.sh run
```

Or run Gradle directly from this directory:

```bash
./gradlew build
./gradlew runClient
```
